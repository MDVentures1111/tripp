## Phase 2: signed-upload transport proof
Use synthetic documents only. Enable issuance **in staging only**, temporarily.
Check exact quarantine path, no ability to write source, overwrite/replay behavior, token expiration, bucket MIME and size caps, restrictive storage policy compatibility, valid PDF/DOCX, and malformed/oversized payload rejection.
Capture the actual response status and Storage metadata for every case.
Turn the flag off immediately after tests.

## Phase 3: recovery and concurrency
Test simultaneous finalize calls, stale leases, interrupted promotion, post-promotion/pre-READY crash, recovery retries, pending expiry and cleanup, and secret-protected reconciler.
Inspect source bytes and metadata after each test.
Do not schedule the reconciler until safe retention and execution budgets are verified.

Even if staging passes, production promotion requires explicit review of audit findings C1-C5, a recorded test report, rollback instructions, and user approval.
